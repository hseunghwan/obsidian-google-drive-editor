Support

Questions, bug reports, and feature requests for Drive Obsidian Editor.

Get in touch

  • Email: contact@cycle1223.com
  • Bug reports and feature requests: GitHub Issues

Emails are usually answered within a few business days. When reporting a problem, it helps to include your browser, whether you opened the file from Drive or from the extension, and the exact message shown on screen.

Common questions

Opening a file from Drive asks for access every time

The editor asks Google for permission the first time you open a document. If the prompt keeps returning, check that third-party cookies and pop-ups are allowed for accounts.google.com, then reload the page.

Nothing happens when I choose "Open with"

Your browser may have blocked the pop-up used for the Google sign-in. Look for the blocked-pop-up icon in the address bar, allow it, and use the "Connect Google Drive" button on the page.

A save failed and I don't want to lose my text

Unsaved text is kept as a local draft in your browser and restored when you reopen the document. Do not clear site data before the save succeeds. Retry the save once your connection is back.

The document changed somewhere else

The editor checks the file in Drive while you work and warns you when the same document was modified elsewhere, so a newer version is not silently overwritten. Reload the document to pick up the remote change.

I want the file explorer and search over a whole folder

Opening a file from Drive gives you the editor for that document. To browse a whole Drive folder as a vault, install the Chrome extension.

How do I revoke access?

Disconnect the account inside the app, or remove access at Google Account permissions. See the Privacy Policy for what the app can access.
