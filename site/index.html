Drive Obsidian Editor

Google Drive에 보관해 둔 Markdown 노트를 브라우저에서 바로 열고 편집하는 Chrome 확장입니다. Obsidian을 설치하지 않은 PC에서도 Drive 폴더 하나를 vault처럼 연결해 문서를 찾고, 쓰고, 저장할 수 있습니다.

Chrome 웹 스토어에서 설치

주요 기능

  • 선택한 Google Drive 폴더를 노트 vault로 연결
  • Markdown 문서 탐색, 편집, 새 파일·폴더 생성
  • 파일 이름과 경로 기반 빠른 검색
  • 자동 저장, 저장 실패 시 로컬 초안 보존, 원격 변경 충돌 감지
  • YAML frontmatter 프로퍼티와 태그 확인
  • 내부 링크·태그·프로퍼티 입력을 돕는 자동완성
  • 노트 사이 연결을 보여주는 그래프 뷰
  • 한국어·영어, 라이트·다크 테마

데이터 처리 방식

확장은 브라우저 안에서만 동작합니다. 자체 서버가 없고, 노트 내용은 Google Drive API로 사용자의 Drive와 직접 주고받습니다. 개발자는 사용자의 파일이나 계정 정보를 수집하거나 저장하지 않습니다. 자세한 내용은 개인정보처리방침을 참고하세요.
