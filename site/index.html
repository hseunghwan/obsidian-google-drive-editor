Drive Obsidian Editor

A Chrome extension that opens and edits the Markdown notes you keep in Google Drive, right in the browser. Connect a single Drive folder as a vault and browse, write, and save your notes on any machine — no Obsidian install required.

Install from the Chrome Web Store

Features

  • Connect any Google Drive folder as a note vault
  • Browse and edit Markdown documents; create new files and folders
  • Fast search across file names and paths
  • Autosave, local draft recovery when a save fails, and remote change conflict detection
  • YAML frontmatter properties and tags in a side panel
  • Autocomplete for internal links, tags, and properties
  • Graph view of the links between your notes
  • English and Korean interface, light and dark themes

How your data is handled

The extension runs entirely in your browser. There is no backend server: note contents move directly between your browser and your Drive through the Google Drive API. The developer does not collect or store your files or account information. See the Privacy Policy for details.
