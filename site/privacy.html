Privacy Policy

Last updated: August 25, 2026

Drive Obsidian Editor ("the extension") is a Chrome extension for editing Markdown files stored in your Google Drive. The extension has no backend server. The developer does not collect, receive, store, or transmit your files, note contents, or account information.

1. Information accessed and why

Google account authentication

The extension uses Chrome's identity API to obtain a Google OAuth access token. The token is managed by Chrome and is used only to call the Google Drive API. It is never sent to the developer.

Google Drive data

Requested scope: https://www.googleapis.com/auth/drive

It is used only to:

  • list the folders and files inside the folder you connect as a vault
  • read the contents of a Markdown file you open
  • save your edits back to that same file
  • create, rename, and delete files and folders when you ask for it
  • read file modification times and revision metadata to detect changes made elsewhere

Drive data travels directly between your browser and Google. It does not pass through any developer-operated server.

2. Information stored locally

The following is kept only in your browser's local storage and is never transmitted anywhere:

  • the ID and name of the folder you connected as a vault
  • the last opened file and your recent file list
  • interface preferences such as editor mode, sidebar width, and graph view settings
  • temporary drafts that prevent content loss when a save fails

Removing the extension from Chrome deletes this data.

3. Sharing and selling

The extension does not share or sell user data to third parties. It contains no ads, analytics, or tracking scripts. The only network destinations are googleapis.com, accounts.google.com, and oauth2.googleapis.com.

4. Google API Services User Data Policy

Drive Obsidian Editor's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. Revoking access

You can disconnect your account from within the extension, which revokes the token. You can also revoke access at any time at Google Account permissions.

6. Children's privacy

The extension is not directed at children under 13 and does not knowingly collect personal information from them.

7. Changes to this policy

If this policy changes, the updated version will be posted on this page with a new revision date.
