Drive Obsidian Editor(이하 "본 확장")는 Google Drive에 저장된 Markdown 파일을 브라우저에서 편집하는 Chrome 확장 프로그램입니다. 본 확장은 자체 서버를 운영하지 않으며, 개발자는 사용자의 파일, 노트 내용, 계정 정보를 수집하거나 전송받지 않습니다.

1. 접근하는 정보와 사용 목적

Google 계정 인증 정보

Chrome의 identity 기능으로 Google OAuth 액세스 토큰을 발급받습니다. 토큰은 Chrome이 관리하며 Drive API 호출에만 사용됩니다. 개발자에게 전송되지 않습니다.

Google Drive 데이터

요청 권한: https://www.googleapis.com/auth/drive

사용 목적은 다음으로 한정됩니다.

  • 사용자가 vault로 연결한 폴더와 그 하위 폴더·파일 목록 조회
  • 선택한 Markdown 파일 내용 읽기
  • 편집한 내용을 같은 파일에 저장
  • 사용자가 요청한 파일·폴더 생성, 이름 변경, 삭제
  • 다른 기기에서 발생한 변경을 감지하기 위한 파일 수정 시각·리비전 확인

Drive 데이터는 사용자의 브라우저와 Google 서버 사이에서만 직접 전송됩니다. 개발자 서버를 경유하지 않습니다.

2. 로컬에 저장되는 정보

다음 정보는 사용자 브라우저의 로컬 저장소에만 보관되며 외부로 전송되지 않습니다.

  • 연결한 vault 폴더의 ID와 이름
  • 마지막으로 열었던 파일, 최근 파일 목록
  • 편집기 모드, 사이드바 너비, 그래프 뷰 설정 등 화면 설정
  • 저장 실패 시 내용 손실을 막기 위한 임시 초안

Chrome에서 확장을 삭제하면 이 정보도 함께 삭제됩니다.

3. 제3자 제공 및 판매

본 확장은 사용자 데이터를 제3자에게 제공하거나 판매하지 않습니다. 광고, 분석 도구, 추적 스크립트를 포함하지 않습니다. 네트워크 통신 대상은 googleapis.com, accounts.google.com, oauth2.googleapis.com 뿐입니다.

4. Google API Services User Data Policy

본 확장이 Google API로부터 받은 정보의 사용 및 전송은 Google API Services User Data Policy의 Limited Use 요건을 포함해 해당 정책을 준수합니다.

Drive Obsidian Editor's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. 권한 철회

확장 내 계정 연결 해제 기능으로 토큰을 폐기할 수 있습니다. Google 계정 권한 설정에서 직접 접근 권한을 철회할 수도 있습니다.

6. 아동 개인정보

본 확장은 만 13세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

7. 변경 고지

본 방침이 변경되면 이 페이지에 수정일과 함께 게시합니다.

English summary

Drive Obsidian Editor is a Chrome extension that edits Markdown files stored in the user's Google Drive. It has no backend server. The developer does not collect, receive, store, or transmit user files, note contents, or account information.

The extension requests the https://www.googleapis.com/auth/drive scope solely to list, read, create, rename, delete, and save files inside the Drive folder the user connects as a vault, and to detect remote changes. All Drive traffic goes directly between the user's browser and Google. OAuth tokens are managed by Chrome and are never sent to the developer.

Local browser storage keeps only the connected folder ID and name, recently opened files, UI preferences, and temporary drafts that protect unsaved work. Uninstalling the extension removes them.

No data is sold or shared with third parties. There are no ads, analytics, or tracking. Users may disconnect the account inside the extension or revoke access at myaccount.google.com/permissions. Contact: contact@cycle1223.com.
