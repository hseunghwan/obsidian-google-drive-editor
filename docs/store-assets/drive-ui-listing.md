## Short description (en, 76 chars)

Open and edit the Markdown notes in your Google Drive, right in the browser.

## 긴 설명 (ko)

Drive Obsidian Editor는 Google Drive에 보관한 Markdown 노트를 브라우저에서 그대로 열어 편집하는 도구입니다. 파일을 다른 서비스로 옮기거나 별도 포맷으로 변환할 필요가 없습니다.

Drive에서 .md 파일을 우클릭해 "연결 앱으로 열기"를 선택하면 편집기가 바로 열립니다. 폴더에서 "새로 만들기"로 빈 Markdown 문서를 만들 수도 있습니다.

주요 기능
- Markdown 문서 열기, 편집, 저장. 자동 저장과 수동 저장 모두 지원
- 저장이 실패하면 작성 중이던 내용을 로컬 초안으로 보존
- 다른 기기에서 같은 파일이 바뀐 경우 원격 변경 감지
- YAML frontmatter 프로퍼티와 태그를 옆 패널에서 확인
- 내부 링크, 태그, 프로퍼티 입력을 돕는 자동완성
- 노트 사이 연결을 보여주는 그래프 뷰
- 문서 이력에서 이전 버전 내용 확인
- 한국어와 영어, 라이트와 다크 테마
- 데스크톱과 모바일 브라우저 모두 지원

Chrome 확장을 함께 설치하면 Drive 폴더 하나를 vault처럼 연결해 파일 탐색기, 빠른 검색, 폴더 정리까지 사용할 수 있습니다.

데이터 처리
자체 서버가 없습니다. 노트 내용은 브라우저와 Google Drive 사이에서 직접 오가며, 개발자는 파일이나 계정 정보를 수집하거나 저장하지 않습니다. Drive에서 열거나 만든 문서에만 접근합니다.

## Long description (en)

Drive Obsidian Editor opens the Markdown notes you keep in Google Drive and lets you edit them in the browser. Nothing moves to another service and nothing is converted to another format.

Right-click a .md file in Drive and choose "Open with" to jump straight into the editor. You can also use "New" inside a folder to start an empty Markdown document.

Features
- Open, edit, and save Markdown documents, with both autosave and manual save
- Keeps your work as a local draft when a save fails
- Detects remote changes when the same file is edited on another device
- Shows YAML frontmatter properties and tags in a side panel
- Autocomplete for internal links, tags, and properties
- Graph view of the links between your notes
- Revision history for reading earlier versions of a document
- English and Korean interface, light and dark themes
- Works in both desktop and mobile browsers

Install the companion Chrome extension to connect a whole Drive folder as a vault, with a file explorer, fast search, and folder management.

How your data is handled
There is no backend server. Note contents move directly between your browser and your Google Drive, and the developer never collects or stores your files or account information. The app only touches the documents you open or create from Drive.
